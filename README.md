# College Chat Box

College Chat Box is a simple chat application made for college students. 
The idea behind this project is to create a platform where students can 
interact and get answers to common college-related questions.

## About the Project

I made this project to learn how a basic chatbot works and how the frontend 
and backend can be connected together.

The application uses Python for the main logic and a simple intent 
classification system to understand what the user is asking. The responses 
are based on the training data provided in the project.

## Features

- Simple chat interface
- College-related questions and responses
- Intent classification
- Python-based backend
- HTML and CSS frontend
- JSON file for training data

## Technologies Used

- Python
- HTML
- CSS
- JSON
- NLP / Intent Classification
